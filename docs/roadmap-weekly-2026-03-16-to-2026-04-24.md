## April Kanban Backlog (Planned, not current-week scope)

### K1. Visual Andon Card

- Goal:
  - operator cukup lihat warna card untuk tahu prioritas.
- Rules:
  - `Red`: overdue atau `available < required`
  - `Yellow`: mendekati SLA / risk threshold
  - `Green`: aman
- Notes:
  - harus memakai definisi `Available` yang sama dengan modul Inventory.
  - warna tidak boleh hanya kosmetik; wajib punya rule backend yang bisa diaudit.

### K2. Wave Picking / Grouping

- Goal:
  - mengurangi jalan bolak-balik gudang untuk item/lokasi yang sama.
- Scope draft:
  - multi-select request di Kanban Board
  - group menjadi 1 batch picking
  - hasilkan lembar kerja / picking task
- Constraint:
  - fase awal grouping diutamakan per item dan area tujuan, bukan optimizer rute penuh.

### K3. Auto-Trigger PRL Draft From Kanban Shortage

- Goal:
  - shortage `Available` langsung menjadi aksi pembelian/planning.
- Trigger:
  - saat request Kanban valid tetapi stok `Available` kurang.
- Output:
  - create draft di PRL / queue buyer
  - simpan `source_type = kanban_request`
  - simpan `source_ref = request_id`
- Constraint:
  - tidak boleh double-create untuk shortage yang sama.
  - wajib ada guard untuk request yang sudah ditutup atau sudah punya PRL draft terkait.

### K4. Print E-Kanban Tag

- Goal:
  - box fisik yang bergerak dari gudang ke line punya tiket visual + QR.
- Scope draft:
  - tombol print kecil di card Kanban
  - format struk / label
  - isi minimum:
    - QR code
    - item
    - qty
    - area tujuan
- Constraint:
  - format print harus hemat kertas dan cepat dicetak di printer label/receipt.

### Dependency Order

1. Inventory `Available` formula harus locked.
2. `kanban_requests` harus punya SLA/exception field yang stabil.
3. PRL draft harus punya `source_type/source_ref`.
4. Baru UI Andon, grouping, auto-trigger PRL, dan print tag dieksekusi bertahap.

### Explicit Priority

- Bukan scope utama minggu berjalan.
- Ditaruh sebagai backlog April dan/atau batch sesudah quick wins Inventory + UI shortage + backend stabilization selesai.
